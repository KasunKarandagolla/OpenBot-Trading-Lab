# OpenBot Trading Lab skill snapshot — 2026-11-07

This folder contains audited copies for independent evaluation of 27 Trading Lab-specific and Chart-Vision skill assignments across the five named persistent profiles.

The live Codex skill roots contained 42 effective assignment directories across those profiles: the 27 specialist assignments in this snapshot and 15 generic OpenBot baseline assignments (three generic skills in each profile). INVENTORY.md lists all 42 by role and identifies the 15 baseline assignments that are not copied here. The snapshot does not claim that 27 is the total number of skill directories installed in OpenBot.

Each specialist assignment has its own agent directory. Repeated names and identical bytes remain duplicated under every owning agent. The published manifests list exported paths, byte sizes, SHA-256 values, copy status and the verified assignment counts. No agent IDs or local host paths are included.

These are audited copies for independent evaluation. This is not a deployed OpenBot skills directory, not a skill improvement, and not evidence of agent trading ability, skill use, profitability or trading edge. No runtime trading or agent-behavior test was performed.

Two historical Chart-Vision changelog copies have a private local validator path redacted. No trading rule, threshold or reference material was changed. The redaction and its effect are recorded in PUBLICATION-CHECKS.md.
