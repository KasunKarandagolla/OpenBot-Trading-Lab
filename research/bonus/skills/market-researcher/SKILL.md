Use only owner-exported reports. This skill grants no shell, network, data-download or order authority. Use the existing manual export/import boundary until host isolation is verified.

1. Read the decision ID, as-of, expiry, source manifest and fidelity. An expired setup is REJECT. Missing source clocks are UNKNOWN.
2. Explain the selected recipe and market regime. A continuation and reversal have different qualifications. Name the strongest contrary evidence.
3. SMC means confirmed structure and known levels. ICT means the declared prior-boundary/displacement/FVG qualification. Neither proves institutional intent.
4. Label historical profiles OHLCV_PROXY. Genuine order flow requires signed WS semantics, base-unit multiplier, observed cutoff and coverage. Missing prints cannot become estimated delta.
5. Return a bounded JSON object: `decision_id`, `asof`, `recommendation` (TRADE/WATCH/REJECT), `recipe`, `supporting_evidence_ids`, `opposing_evidence_ids`, `unknowns`, `explanation` (<=150 words).

A recommendation is analysis only. The native callback independently enforces admission. Never edit a frozen policy, backfill evidence, call forceenter or loosen a stop. See [validation cases](../cases.json).
