# Known gaps and limits

- Baseline is **EXPLORATORY / UNQUALIFIED** and lost money after modeled fees/funding. No independent holdout, benchmark/random-control study, confidence bound, economic qualification or forward-paper evidence. No optimization was performed.
- Static currently surviving BTC/ETH/SOL selection is not point-in-time historical universe membership. Current native scanner membership never changes the historical test.
- Native candle fills do not establish true limit-order queue position, partial fills, spread, slippage, latency, outages or realistic liquidation. Additional friction scenarios are postprocessing only. Native 15m timing can produce same-bar exits.
- Funding: all 288 expected 8-hour events and 2,304 hourly mark bars per pair in the sealed sample; actual native signed funding contributes to P&L. Validation compares against current venue schedule metadata and detects observed irregularities; it does not independently certify every historical venue rule or mark/funding precision. No zero-funding fallback is configured. Mark volume is zero and is not liquidity.
- Fees: 0.0006 each side is a conservative research assumption, not a verified account tier. The price-only profit before costs was small; fees overwhelmed it. Profitability is not established.
- Engine risk settings are 1x, at most two open positions, 25 USDT configured stake, no adjustment/DCA, -2% stop, +3% ROI, 12h exit request and cooldown. Amount precision can reduce actual stake. Exact 0.25%/0.50% monetary loss ceilings, concentration and a 1% daily new-entry halt are not implemented/guaranteed. Gaps, costs and downtime can exceed modeled stops. Paper exits only operate while application/host run, with no real exchange protective orders.
- Scanner uses current active linear USDT metadata, native volume/spread candidates and 30-day launch metadata; missing quote/spread or unknown age excludes. Venue ticker timestamp can be unknown and is labeled UNKNOWN; receipt time is not an exchange freshness guarantee. No deep volatility/history scan, independent historical delisting calendar or order-book service.
- Gate's personal/noncommercial license and public-data documentation support only this scoped use assessment. No raw dataset redistribution, commercial clearance, customer-facing rights or blanket owner-host jurisdiction determination. Stop on denial/429; no geographic workaround.
- The fixed 15m window will age beyond Gate's recent-10,000-bar REST retention. Preserve local sample files; later re-download may be unavailable. Native original files sometimes exceed the requested end; only out-of-range observations were discarded and receipt hashes/counts were saved. No gaps were filled.
- Cloud Docker VFS duplication exhausted the small disk during early parallel container launches. Recovery removed this session's containers only and reused one official-image runner. Cloud proxy/CA setup is local and excluded from Git, with TLS verification enabled. No paid compute/services or exchange credentials used.
- Official FreqUI HTTP/auth and supported research endpoints are checked separately; graphical owner-browser rendering, Windows/WSL2/macOS installation, local jurisdiction and API reachability remain owner-host verification. Cloud's temporary process does not prove 24/7 operation, SQLite restart/restore behavior with positions, backups or multi-day reliability.
- The guard enforces mode/configuration at the supplied entrypoint. A host administrator can change files, image, mount or entrypoint; this is not an agent sandbox. OpenBot is not installed/integrated. Production OpenBot isolation remains Session 4, with no privileged network bridge.
- A transient exec-server outage interrupted observation of the manual paper smoke; after restoring the same workspace, actual safe-mode state and zero positions were inspected and the process explicitly stopped. It is not forward-paper performance evidence.
