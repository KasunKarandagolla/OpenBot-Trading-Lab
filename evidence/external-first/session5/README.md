labeled SIMULATED. They are source/numerical/operational evidence, not profitable
prediction or full-method certification. UTC receipts can be dated 13 November;
the client date is 14 November 2026 in Asia/Colombo.

- `core-qualification.json`: bounded selected independent Binance bars and remote
  tails, exact ATR starts/initial NULLs/seed/recurrences, 160 scaled scalar checks plus positive pressure tails,

  GitHub publication status is recorded separately. No
  whole-universe candle/feature-value dataset is committed.

  catalogue and quota/rights unknowns; public credential-free access is observed,

- `baseline-tests.txt`, `test-results.txt`, `config-validation.json`, `safety.json`:
