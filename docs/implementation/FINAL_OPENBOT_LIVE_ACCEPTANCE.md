Send exactly one ordinary message:

> Run the complete market research now.

The Researcher should return one job ID and keep its main turn active, giving
progress during scanning and bounded native waits. Expect COMMAND_ATTESTED,
SCANNING, then REVIEW_READY with the complete exact start_task arguments. Each

Subsequent distinct batches can become REVIEW_READY. The review uses zero tools.

persists watches, and creates the sanitized ZIP. The Researcher gives readable
coins/directions/TFs/families/methods, observed sequence, rival, first obstacle,
known/unknown friction, next discriminator, watch status and as-of/valid-until.

- Genuine owner command proof precedes any scan. The same job ID binds the
  report, source/candidate references, native tasks, reconciliation and ZIP.

- No ZIP is delivered before review import or an explicit timeout/failure.
  Failures include the first sanitized stage and cause, not only a generic fallback.
- All 27 measurements, F1–F9 and M01–M31 coverage states are present. Source gaps,
  requested-but-absent versus never-requested rows, quote RVOL, fees, depth and

  visible. Conditional research stays separate from strict READY, which may be
  zero. No positive shortlist size is forced. `trade_authorization=false`.
- ZIP checksums verify and no native database, raw reasoning, private config,
  credential or personal/session material is included.

claim, unreviewed finalists hidden by budget, stale point admission, missing
attachment, fabricated readiness or trading side effect fails acceptance.
A model/source/reader failure is an explicitly incomplete qualification result;
it is not evidence that the market has no opportunities. Prospective research
performance remains a separate observation programme.
